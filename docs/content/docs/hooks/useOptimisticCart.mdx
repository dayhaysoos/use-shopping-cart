**New in v4.0.0** - Optimistic version of `useShoppingCart()` built on React 19's `useOptimistic`. It shows cart changes instantly while your backend confirms them.

## Overview

`useOptimisticCart()` wraps `useShoppingCart()` for carts that sync with your backend. Pass an async `onChange` and every cart change shows in the UI immediately, is sent to `onChange`, and is applied to the real cart once `onChange` resolves. If it rejects, the change is rolled back.

Without `onChange`, its actions apply to the cart immediately, like `useShoppingCart()`. It still shows changes that other `useOptimisticCart({ onChange })` calls on the same cart are waiting on.

## Benefits

✅ **Instant UI feedback** - Changes show while your backend request is in flight  
✅ **Automatic rollback** - If `onChange` rejects, the UI reverts and `error` is set  
✅ **In order** - Changes are sent to `onChange` one at a time, in the order they were made  
✅ **Drop-in replacement** - Returns the same values and actions as `useShoppingCart()` (it takes options, not a selector)

## Requirements

- React 19.0.0 or higher
- use-shopping-cart v4.0.0 or higher

## Basic Usage

The examples on this page use a `syncCart` function that sends each change to your backend:

```jsx
async function syncCart(change) {
  const res = await fetch('/api/cart', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(change)
  })
  if (!res.ok) throw new Error('Could not update cart')
}
```

```jsx
import { useOptimisticCart } from 'use-shopping-cart'

function ProductCard({ product }) {
  const { addItem, isOptimistic } = useOptimisticCart({ onChange: syncCart })

  return (
    <button onClick={() => addItem(product)} disabled={isOptimistic}>
      {isOptimistic ? 'Adding...' : 'Add to Cart'}
    </button>
  )
}
```

## Syncing with Your Backend

```jsx
import { useOptimisticCart } from 'use-shopping-cart'

function Cart() {
  const { cartDetails, incrementItem, isOptimistic, error } = useOptimisticCart(
    {
      onChange: async (change) => {
        const res = await fetch('/api/cart', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(change)
        })
        if (!res.ok) throw new Error('Could not update cart')
      }
    }
  )

  // ...
}
```

`change` describes what happened:

| `type`     | Fields                               | From                             |
| ---------- | ------------------------------------ | -------------------------------- |
| `'add'`    | `product`, `count`, `metadata`       | `addItem`                        |
| `'adjust'` | `id`, `by` (negative for decrements) | `incrementItem`, `decrementItem` |
| `'set'`    | `id`, `quantity`                     | `setItemQuantity`                |
| `'remove'` | `id`                                 | `removeItem`                     |
| `'clear'`  |                                      | `clearCart`                      |

How it behaves:

- **Every component:** `<CartProvider>` holds one `useOptimistic` state per cart, so a pending change shows in every component that calls `useOptimisticCart`. A total in one component updates when a cart entry in another changes. `useShoppingCart` shows only confirmed changes.
- **Order:** changes wait for the previous `onChange` to settle, so three quick clicks send three requests, one after another. Changes made without `onChange` don't wait: they apply to the cart straight away.
- **Success:** the change is applied to the real cart (and saved to `storage`).
- **Failure:** the change is dropped and `error` holds what `onChange` threw, in the component that made the change. Later queued changes still run, but each is checked against the real cart first: one that depended on the failed change (incrementing a cart entry whose add failed) is dropped with an `ITEM_NOT_IN_CART` error and never reaches `onChange`.
- **Rollback timing:** React batches pending transitions together, so if one change fails while others are still pending, its rollback shows once they settle.
- **Invalid input** (bad count, product without a price) throws immediately and never reaches `onChange`.

What the server does with the change, and whether the cart is loaded from the server (for example with [`loadCart`](/docs/actions/loadCart)), is up to you.

## API

### Options

| Option     | Type                                       | Description                                       |
| ---------- | ------------------------------------------ | ------------------------------------------------- |
| `onChange` | `(change: CartChange) => Promise<unknown>` | Called for each change before it reaches the cart |

`useOptimisticCart()` returns the same properties and methods as `useShoppingCart()`, plus:

### Additional Properties

#### `isOptimistic`

- **Type:** `boolean`
- **Description:** `true` when the cart is showing optimistic updates that haven't been confirmed yet

```jsx
const { isOptimistic } = useOptimisticCart({ onChange: syncCart })

{
  isOptimistic && <span>Syncing changes...</span>
}
```

#### `error`

- **Type:** `unknown`
- **Description:** what `onChange` threw for the last change this component made; `null` after one succeeds

#### `pendingIds`

- **Type:** `ReadonlySet<string>`
- **Description:** ids of the cart entries an optimistic change added or changed that the backend hasn't confirmed yet; empty when nothing is in flight

```jsx
const { cartDetails, pendingIds } = useOptimisticCart({ onChange: syncCart })

Object.values(cartDetails).map((item) => (
  <div key={item.id}>
    {item.name} - Qty: {item.quantity}
    {pendingIds.has(item.id) && <span> (updating...)</span>}
  </div>
))
```

## Examples

### Cart with Loading States

```jsx
function ShoppingCart() {
  const {
    cartDetails,
    cartCount,
    formattedTotalPrice,
    clearCart,
    isOptimistic
  } = useOptimisticCart({ onChange: syncCart })

  return (
    <div className="cart">
      <h2>Your Cart ({cartCount} items)</h2>

      {isOptimistic && (
        <div className="syncing-indicator">🔄 Syncing changes...</div>
      )}

      {Object.values(cartDetails).map((item) => (
        <CartItem key={item.id} item={item} />
      ))}

      <div className="cart-total">
        Total:{' '}
        <span className={isOptimistic ? 'updating' : ''}>
          {formattedTotalPrice}
        </span>
      </div>

      <button onClick={clearCart} disabled={isOptimistic}>
        Clear Cart
      </button>
    </div>
  )
}
```

### Cart Item with Quantity Controls

```jsx
function CartItem({ item }) {
  const { incrementItem, decrementItem, removeItem, isOptimistic, pendingIds } =
    useOptimisticCart({ onChange: syncCart })

  return (
    <div className="cart-item">
      <h4>{item.name}</h4>

      <div className="quantity-controls">
        <button
          onClick={() => decrementItem(item.id)}
          disabled={isOptimistic || item.quantity === 1}
        >
          -
        </button>

        <span className={pendingIds.has(item.id) ? 'updating' : ''}>
          {item.quantity}
        </span>

        <button onClick={() => incrementItem(item.id)} disabled={isOptimistic}>
          +
        </button>
      </div>

      <button onClick={() => removeItem(item.id)} disabled={isOptimistic}>
        Remove
      </button>
    </div>
  )
}
```

### Advanced: Per-Item Loading

```jsx
function ProductCard({ product }) {
  const { addItem, cartDetails, pendingIds } = useOptimisticCart({
    onChange: syncCart
  })

  const itemInCart = cartDetails[product.id]
  const isThisItemOptimistic = pendingIds.has(product.id)

  return (
    <div className="product">
      <h3>{product.name}</h3>
      <p>${product.price / 100}</p>

      {itemInCart && (
        <div className="in-cart-badge">
          In cart: {itemInCart.quantity}
          {isThisItemOptimistic && ' (updating...)'}
        </div>
      )}

      <button onClick={() => addItem(product)} disabled={isThisItemOptimistic}>
        {isThisItemOptimistic ? 'Adding...' : 'Add to Cart'}
      </button>
    </div>
  )
}
```

## Migration from useShoppingCart()

Replace `useShoppingCart` with `useOptimisticCart` and pass the function that syncs with your backend:

```diff
- import { useShoppingCart } from 'use-shopping-cart'
+ import { useOptimisticCart } from 'use-shopping-cart'

function MyComponent() {
-  const { addItem, cartCount } = useShoppingCart()
+  const { addItem, cartCount, isOptimistic } = useOptimisticCart({
+    onChange: syncCart
+  })

  return (
    <button onClick={() => addItem(product)}>
-      Add to Cart
+      {isOptimistic ? 'Adding...' : 'Add to Cart'}
    </button>
  )
}
```

## When to Use

Use `useOptimisticCart()` when:

- Your cart syncs with a backend and you want changes to show before the request finishes

Stick with `useShoppingCart()` when:

- The cart lives only in the browser (it's already instant)
- You sync with a backend some other way, for example with `subscribe`
